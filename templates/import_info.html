CSV File Requirements

To bulk-import tax returns, upload a CSV file with the following structure:

Required Columns

  • Return Name — Individual or company name
  • Tax Year — Four-digit year (e.g., 2025)
  • Return Type — Form type (e.g., 1040, 1120-S)

Optional Columns

  • Due Date — Format: YYYY-MM-DD or MM/DD/YYYY
  • Extended Due Date — Format: YYYY-MM-DD or MM/DD/YYYY
  • Signer — Name of assigned signer
  • Status — One of your workflow status labels; anything unrecognized causes that row to be skipped

Column Matching

Header names are matched case-insensitively and ignoring punctuation/spaces. So "Return_Name", "returnname", or "Return Name" will all be recognized.

How to Import

  1. Upload your CSV file above using the Browse button
  2. Click Import CSV to submit
  3. New returns are added to the bottom of the workflow (status: Not Started)
  4. Duplicate rows are skipped and reported back to you
  5. Any validation errors (invalid dates, unknown status) are listed in the results

The imported returns appear immediately on the All Returns page.
